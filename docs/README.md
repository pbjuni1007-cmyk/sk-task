## 현재 검증 상태

- 화면 다듬기: 상품 선택 강조, 데스크톱 AI 패널(최대 720px)·다음 단계 영역 고정, 대화 내부 스크롤, 저장 Markdown 렌더링, 한국어·한국 시간 결재 이력, 처리별 확인 버튼을 반영했다. 상품 선택·문서 생성·고정 배치는 Chrome에서 확인했다.
- Agent 중심 주 시연: 명시한 34U620B·50만 원 예산으로 1대 399,000원 → 2대 798,000원 제출 차단 → 90만 원 예산 보완 → 제출 확인 대기까지 실제 AI로 확인했다. 선택 기준만 위임한 초기 검증에서는 다른 상품 선택·예산 해석이 발생하여, 가이드는 모델명과 구매 예산을 명시한다. 자동 선택의 안정성은 별도 개선이 필요하다.
- 오류 진단: 허용된 오류 코드와 문의 번호를 UI·서버 로그에 남긴다. 이전 간헐적 제출 오류의 원인은 아직 확정되지 않았으며, 이 변경은 재발 시 진단을 위한 것이다.

- 확인일: 2026-09-11. `aed397a` 이후 예산 없는 탐색·진행 표시·가드레일 분리 코드의 로컬 검사 결과다.
- `make check`: 자동 테스트 **135개 통과**, Ruff 린트·포맷 및 Prettier 검사 통과. 화면 테스트 15개를 포함한다.
- 추가 자동 검증: 예산 없는 탐색과 조건 보존, 서버 부서 예산·권한, 후보의 정식 요청 이관, 전체 12개 상품과 LG전자 정정, 스트림 집계·키 전환·부분 응답 실패.
- 실제 브라우저 추가 검증: Chrome에서 상품 검색 중 표시 → 예산 없는 후보·수량/목적 유지 → 모의 예산 안내 → 399,000원 문서 및 잔액 101,000원 → AI 제출 확인 중단·취소 후 미제출 상태를 확인했다.
- 실제 AI 추가 검증: 원래 두 문장으로 예산 없이 탐색 → 수량 1대·목적 유지 → 모의 예산 50만 원 → LG 34U620B 399,000원 문서 3종·제출 가능 상태를 확인했다.
- 화면 자동 검증: 직접/AI 공통 제출 확인, 취소, 변경된 문서 제출 차단, 사용자별·요청별 대화 분리, AI와 양식 수정의 상호 반영, 보완 후 재제출, 100만 원 이상 추가 승인, 과거 버전 읽기 전용, 최신 생성 순 목록.
- 실제 브라우저: 별도 임시 DB와 쿠팡 모의 상품 자료로 양식 작성 → 3대 342,000원 제출·취소·재제출 → 구매 담당자 승인 완료를 확인했다. 보완 요청의 의견 필수 동작도 확인했다.
- 실제 AI: 검색 → 화면에서 상품 선택 → AI로 4대 변경·문서 생성 → 총액 456,000원·잔액 144,000원 → 목록 이동 후 대화 유지 → AI 제출 취소·재요청·제출 완료를 확인했다. 새 요청에는 이전 대화가 표시되지 않았다.
- 배치 검증: 데스크톱 1440×1000과 모바일 390×844에서 작성 화면을 확인했다. 좁은 화면에서 사이드바를 접으면 제목·입력·단계 표시가 정상 배치된다. 모든 모바일 화면을 검증한 것은 아니다.
- 실제 AI 성능 20회 평가, 오류 주입, 다운로드 파일 저장 완료는 이번 개편에서 다시 검증하지 않았다. [2026-09-10 기록](validation/BROWSER_QA_REPORT.md)은 과거 근거로 보존한다. CI 성공 여부는 로컬 결과와 별개다.

## 문서 관리 기준

현재 자동 검사 수치는 이 페이지에서 관리한다. 과거 보고서의 날짜·수치와 원본 JSON은 당시 근거로 보존한다. 테스트 추적표는 “어떤 코드가 검증하는가”, 브라우저 보고서는 “당시 화면에서 무엇을 관찰했는가”를 담당한다.

시연 절차는 시연 가이드, 개발 명령은 개발 안내, 상품 조건은 상품 자료, API 필드는 API 대조 문서를 기준으로 한다. 다른 문서는 필요한 요약과 링크를 둔다. 별도 설명이 없는 실행 명령은 저장소 루트 기준이다.
